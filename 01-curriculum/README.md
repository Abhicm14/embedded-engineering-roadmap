# 🎓 6-Month Embedded Engineering Curriculum

> A complete 6-month, structured learning path for students and engineers. Each month contains dedicated theoretical modules, hands-on lab exercises, and capstone milestones.

---

## 📅 Monthly Navigation

| Module | Core Domain | Key Deliverable |
| :--- | :--- | :--- |
| [**Month 1: C & Electronics Foundations**](month-01-c-and-electronics/) | Bitwise operations, pointers, memory models, circuit theory, and oscilloscope probing. | Bitwise register library & circuit breadboard validation. |
| [**Month 2: Microcontroller & STM32 Bare-Metal**](month-02-microcontroller-and-stm32/) | Cortex-M4 internals, vector table, custom linker script, Makefiles, RCC clock trees. | [Project 1: Bare-Metal GPIO & SysTick FSM](../04-portfolio-projects/project-01-baremetal-gpio-systick/) |
| [**Month 3: Peripherals & Protocols**](month-03-peripherals-and-protocols/) | UART with circular DMA, SPI transactions, I2C master driver, Timers, PWM, NVIC. | [Project 2: I2C BMP280 Driver & DMA UART Shell](../04-portfolio-projects/project-02-i2c-sensor-uart-dma/) |
| [**Month 4: Real-Time Operating Systems (RTOS)**](month-04-rtos/) | FreeRTOS kernel mechanics, TCB, context switching, queues, semaphores, mutexes (PIP). | [Project 3: Multitasking Environmental Data Logger](../04-portfolio-projects/project-03-freertos-data-logger/) |
| [**Month 5: Embedded Linux & Architecture**](month-05-embedded-linux/) | Cross-toolchains, U-Boot, Device Tree Source, Linux kernel character driver, `sysfs`. | [Project 5: Custom Linux Driver & POSIX App](../04-portfolio-projects/project-05-embedded-linux-driver/) |
| [**Month 6: Advanced Specializations**](month-06-advanced-specializations/) | Automotive CAN/AUTOSAR, Secure IoT Edge with TLS/OTA, and TinyML Edge AI. | Projects 4, 6, or 7 Capstone Showcase |
